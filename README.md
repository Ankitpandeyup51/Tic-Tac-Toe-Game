🎮 Tic Tac Toe Game
============================================================================================================================

A classic game of strategy, fun, and friendly competition! Built with HTML, CSS, and JavaScript. 

✨ About The Project
============================================================================================================================

Tic Tac Toe is a fun and lightweight browser game where two players compete to align three symbols in a row. Enjoy a simple, interactive, and user-friendly gaming experience!

🚀 Key Features
=============================================================================================================================

🎮 Two-Player Gameplay — Challenge your friends.

🏆 Winner Detection — Automatically detects the winner.

🤝 Draw Detection — Identifies a tie when the board is full.

🔄 Restart Option — Start a new game anytime.

🎨 Clean Interface — Simple and easy to use.

⚡ Lightweight & Fast — Play directly in your browser.

🛠️ Tech Stack
=========================================================================================================================

Technology	Description :

🌐 HTML5	Structures the game interface.

🎨 CSS3	Adds styling and visual design.

⚡ JavaScript	Powers the game logic and interactions.



🎯 How to Play
===============================

Player X starts the game.
Players take turns selecting an empty cell.
Align three matching symbols horizontally, vertically, or diagonally to win.
If all cells are filled without a winner, the game ends in a draw.
Use the restart option to play again.
